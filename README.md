# Clank Spettro — versione web

Il synth spettrale **Clank Spettro** nel browser: il suono è il firmware
dello strumento compilato in WebAssembly, il pannello è quello vero.

**Provalo:** apri la pagina del sito e fai clic sul pannello per accendere l'audio.

- Funziona con Chrome, Edge e Firefox recenti; per il MIDI serve Chrome o Edge.
- Manopole e fader si trascinano (shift per la regolazione fine), doppio clic
  per il valore iniziale. Sullo schermo: clic sulle voci, frecce, rotella.
- **keyboard mode** (tasto `): Q…I, A…K, Z…, suonano le tre file di pad;
  1-4 ottave, spazio hold, 5 arpeggio, 6 registrazione dei movimenti.
- Il banco 0 contiene 24 preset di fabbrica; i preset salvati restano solo
  in questo browser.
